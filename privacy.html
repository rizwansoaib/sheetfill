SheetFill Privacy Policy

Last Updated: September 20, 2026

SheetFill is a Chrome extension that helps users fill supported web forms using data from Excel and CSV spreadsheets.

This Privacy Policy explains how SheetFill handles information when you use the extension.

1. Information We Process

SheetFill may process information that you voluntarily provide while using the extension, including:

  • Excel or CSV spreadsheet data selected by you.
  • Spreadsheet headers, rows, columns, and cell values used during the workflow.
  • Web-form field information that you select or allow SheetFill to interact with.
  • Extension settings and configuration data.
SheetFill does not require you to create a SheetFill account or submit your spreadsheet data to a SheetFill cloud service for its core workflow.

2. How Spreadsheet Data Is Used

Spreadsheet data is used to provide the functionality requested by you, such as previewing spreadsheet contents, selecting rows and columns, and filling supported web-form fields.

SheetFill does not use your spreadsheet data for advertising, profiling, or unrelated purposes.

3. Webpage Access

SheetFill may access the webpage where you choose to use the extension in order to identify supported form elements, allow you to select fields, map fields, and fill those fields with spreadsheet data.

SheetFill is designed to perform these actions only as part of the extension's core spreadsheet-to-web-form functionality.

4. Chrome Extension Permissions

SheetFill requests certain Chrome permissions to provide its core functionality:

  • activeTab: Used to interact with the currently active webpage when you use SheetFill.
  • scripting: Used to identify and interact with supported webpage form elements for field selection, mapping, and filling.
  • storage: Used to store extension settings and configuration.
  • unlimitedStorage: Used when additional browser storage is required for the extension's workflow data or configuration.
  • Host permissions: Used to allow SheetFill to interact with supported webpages where you choose to use the extension.

5. Data Storage

SheetFill is designed around user-controlled browser workflows. The extension does not require a SheetFill cloud account for its core functionality.

Information stored by the extension may include settings, configuration, and data required to perform the workflow you initiate.

6. Data Sharing

SheetFill does not sell, rent, or share your spreadsheet data with third parties for advertising or unrelated purposes.

SheetFill does not require your spreadsheet data to be uploaded to a SheetFill-operated cloud service for the core spreadsheet- to-web-form workflow.

7. Advertising and Analytics

SheetFill does not use your spreadsheet or web-form data for targeted advertising.

If third-party analytics, advertising, or other external services are added to the extension in the future, this Privacy Policy will be updated before those services are used to process applicable user data.

8. File Upload Fields

SheetFill currently does not automatically handle photographs, signatures, or other file-selection fields. These fields may require manual handling by the user.

9. Data Security

SheetFill is designed to minimize unnecessary data transmission and keep the core workflow under the user's control.

However, users should avoid entering sensitive information into websites unless they are authorized to do so and trust the destination website.

10. Children's Privacy

SheetFill is a general-purpose productivity extension and is not specifically directed toward children.

11. Responsible Use

SheetFill should only be used for legitimate and authorized data-entry activities.

Users must not use SheetFill to bypass CAPTCHA systems, authentication, access restrictions, security controls, anti-automation protections, or website usage restrictions.

12. Changes to This Privacy Policy

This Privacy Policy may be updated when SheetFill's functionality, data practices, or applicable requirements change.

The latest version will be published on this page with an updated effective date.

13. Contact

If you have questions about this Privacy Policy or SheetFill's data practices, please contact the SheetFill developer through the contact information provided on the Chrome Web Store listing.
